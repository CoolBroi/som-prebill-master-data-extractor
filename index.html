1. Upload workbooks

The tool detects columns named Tower and Track. If your template uses different headers, you can select them below.
Upload both Excel files to begin.

2. Review RU sheet → Tower / Track mapping

Each Pre-Bill worksheet is listed separately. Select the correct Tower and Track. The extractor will use these assignments for rows taken from that worksheet; no uncertain mapping is silently guessed.

3. Populate and download

Choose how rows are matched to existing template rows. For safety, the default is to append extracted rows beneath the template's existing data. You can instead match using a common key column.
